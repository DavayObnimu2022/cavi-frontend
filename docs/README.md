# CAVI Мониторинг — фронтенд (лабораторная 5)

SPA на `React` + `TypeScript` (сборщик `Vite`) с компонентами `React-Bootstrap`.
Интерфейс для **гостя**: просмотр услуг — лента и плитка.
Данные карточек берутся только из mock-коллекции `src/collections/services.ts`, бэкенд не используется.
Redux и Context не используются.

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверки:

```bash
npm run typecheck
npm run lint
npm run build
```

## Общие элементы всех страниц

- **Статус-бар** сверху — время и значки, как в макете экрана телефона из лабораторной 1.
- **Навигационная панель** снизу из 4 пунктов.

| Пункт | Адрес | Доступность |
|---|---|---|
| Лента | `/feed` | доступен |
| Добавление | `/add` | недоступен для гостя |
| Плитка | `/grid` | доступен |
| Вход | — | недоступен для гостя |

Пункт текущей страницы выделяется цветом и фоном.

## Страница «Лента» — `/feed`

Одна услуга на весь экран.

- `/feed` — первая услуга из коллекции.
- `/feed?service=<id>` — услуга с указанным `id` (используется при переходе из плитки).
- Если услуги с таким `id` нет, показывается первая услуга.

### Поля на странице

Полей ввода нет.

### Кнопки и элементы страницы

| Элемент | Тип | Назначение |
|---|---|---|
| Видео | фон | видео услуги на весь экран (автовоспроизведение, без звука, по кругу); если поле `videoUrl` пустое — видео по умолчанию |
| Изображение | `poster` видео | изображение услуги; если поле `imageUrl` пустое — изображение по умолчанию |
| «Возраст … лет / Давление … мм» | текст | характеристики услуги |
| Сердце и число | кнопка | поставить или убрать лайк; счётчик меняется в состоянии страницы |
| Стрелка вправо | кнопка | перейти к следующей услуге (после последней — снова первая) |
| Название и описание | текст | название и описание услуги (описание обрезано до 2 строк) |
| «Ещё» | ссылка | перейти на страницу «Плитка» |
| Лента | пункт нижней панели | активный пункт |
| Плитка | пункт нижней панели | перейти на страницу «Плитка» |
| Добавление | пункт нижней панели | отключён для гостя |
| Вход | пункт нижней панели | отключён для гостя |

## Страница «Плитка» — `/grid`

Каталог услуг карточками в две колонки и фильтр по возрасту.

### Поля фильтра

| Поле | Тип | Назначение |
|---|---|---|
| «Возраст: От» | ползунок (`range`) | минимальный возраст, 0–100, шаг 1 |
| «Возраст: До» | ползунок (`range`) | максимальный возраст, 0–100, шаг 1 |

Текущий диапазон выводится текстом: `Возраст: от … до …`.

### Кнопки и элементы страницы

| Элемент | Тип | Назначение |
|---|---|---|
| «Применить» | кнопка | применяет фильтр: остаются услуги с возрастом в выбранном диапазоне |
| Карточка услуги | ссылка | изображение по умолчанию, название, возраст и количество лайков; нажатие открывает услугу в ленте |
| Лента | пункт нижней панели | перейти на страницу «Лента» |
| Плитка | пункт нижней панели | активный пункт |
| Добавление | пункт нижней панели | отключён для гостя |
| Вход | пункт нижней панели | отключён для гостя |

При открытии страницы показываются все услуги. Если по выбранному возрасту ничего не найдено, выводится сообщение «Нет услуг по выбранным фильтрам».

## Страница «Добавление» — `/add`

Третий экран приложения. Для гостя недоступен: пункт «Добавление» в нижней панели отключён.

### Поля формы

Все поля отключены для гостя.

| Поле | Тип | Назначение |
|---|---|---|
| Название | текстовое поле | название услуги |
| Краткое описание | многострочное поле | описание услуги |
| Цена, ₽ | числовое поле | стоимость услуги |
| Дата | поле выбора даты | дата оказания услуги |
| Категория | выпадающий список | категория услуги |

### Кнопки и элементы страницы

| Элемент | Тип | Назначение |
|---|---|---|
| «Добавить» | кнопка | отключена для гостя |
| «Вернуться в ленту» | ссылка | перейти на `/feed` |
| Лента | пункт нижней панели | перейти на страницу «Лента» |
| Добавление | пункт нижней панели | отключён для гостя |
| Плитка | пункт нижней панели | перейти на страницу «Плитка» |
| Вход | пункт нижней панели | отключён для гостя |

## Медиа по умолчанию

У всех услуг в mock-коллекции поля `imageUrl` и `videoUrl` пустые, поэтому везде показываются одни и те же медиа:

- `src/assets/default-image.svg` — изображение по умолчанию;
- `src/assets/default-video.mp4` — видео по умолчанию;
- `src/components/ServiceMedia.tsx` — компонент, который подставляет медиа по умолчанию, если поле пустое или файл не загрузился.

## Mock-данные

Коллекция находится в `src/collections/services.ts`. Каждый объект услуги содержит:

```ts
interface Service {
  id: string
  title: string
  description: string
  category: string
  price: number
  date: string
  age?: number
  pressure?: number
  likes: number
  imageUrl?: string
  videoUrl?: string
}
```

## Фильтрация и props

Компонент `src/components/ServiceFilter.tsx` — управляемый компонент. Он получает props:

- `values` — текущие значения фильтра `{ minAge, maxAge }`;
- `onChange` — обновление значений при движении ползунков;
- `onApply` — применение фильтра.

Страница плитки хранит два состояния: черновик фильтра и применённый фильтр. Список услуг пересчитывается через `useMemo`.

## Используемые хуки

- `useState` — состояние ленты, лайков, фильтра и применённого фильтра;
- `useEffect` — установка заголовка документа при смене услуги;
- `useMemo` — вычисление отфильтрованного списка услуг;
- `useSearchParams` — получение `service` из URL, чтобы открыть нужную услугу из плитки.

## Структура проекта

```text
src/
  assets/            изображение и видео по умолчанию
  collections/       mock-коллекция услуг
  components/        layout, navbar, карточки, фильтр, медиа, иконки
  pages/             FeedPage, GridPage, AddPage
  App.tsx            маршруты
  main.tsx           точка входа, Bootstrap CSS, BrowserRouter
```

## Ограничения

- Бэкенд не используется: все карточки берут данные из mock-коллекции.
- Redux и Context не используются.
- Авторизации нет: гость видит только ленту и плитку.
- Лайки и фильтр хранятся только в состоянии страницы и сбрасываются при перезагрузке.
