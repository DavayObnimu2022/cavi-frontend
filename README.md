# CAVI Мониторинг — frontend

SPA на React + TypeScript для гостевого просмотра услуг. Данные берутся только из mock-коллекции, без бэкенда. Redux и Context не используются.

## Стек

- React 19 + TypeScript
- Vite
- React Router
- React-Bootstrap + Bootstrap 5
- Oxlint

## Быстрый старт

```bash
npm install
npm run dev
```

Приложение откроется по адресу, который выведет Vite (обычно `http://localhost:5173`).

Сборка и проверки:

```bash
npm run typecheck
npm run lint
npm run build
npm run preview
```

## Маршруты

| Маршрут | Страница | Доступ |
|---|---|---|
| `/feed` | Лента | Гость |
| `/grid` | Плитка | Гость |
| `/add` | Добавление | Только авторизованный пользователь |

## Страницы приложения

### Лента — `/feed`

Показывает одну услугу из mock-коллекции. Это главная страница гостя.

**Что отображается:**

- видео услуги на весь экран;
- изображение услуги как `poster` для видео;
- бейджи с возрастом и давлением;
- название и краткое описание услуги;
- нижняя навигационная панель.

**Поля на странице:** полей ввода нет.

**Кнопки и ссылки на странице:**

| Элемент | Тип | Действие |
|---|---|---|
| Сердце | кнопка | Поставить или убрать лайк, счётчик меняется в состоянии страницы |
| Стрелка вправо | кнопка | Перейти к следующей услуге |
| Ещё | ссылка | Перейти на страницу «Плитка» |
| Лента | пункт нижней панели | Активный пункт, остаётся на ленте |
| Плитка | пункт нижней панели | Перейти на страницу «Плитка» |
| Добавление | пункт нижней панели | Отключён для гостя |
| Вход | пункт нижней панели | Отключён для гостя |

Если у услуги пустые поля `imageUrl` или `videoUrl`, используется единое изображение/видео по умолчанию из `src/assets`.

### Плитка — `/grid`

Сетка карточек услуг с фильтром по возрасту.

**Поля фильтра:**

| Поле | Тип | Назначение |
|---|---|---|
| Возраст: От | ползунок | Минимальный возраст |
| Возраст: До | ползунок | Максимальный возраст |

**Кнопки и ссылки на странице:**

| Элемент | Тип | Действие |
|---|---|---|
| Применить | кнопка | Применить выбранный диапазон возраста к списку |
| Карточка услуги | ссылка | Открыть эту услугу в ленте |
| Лента | пункт нижней панели | Перейти на страницу «Лента» |
| Плитка | пункт нижней панели | Активный пункт, остаётся на плитке |
| Добавление | пункт нижней панели | Отключён для гостя |
| Вход | пункт нижней панели | Отключён для гостя |

**Карточка плитки содержит:**

- изображение по умолчанию;
- название услуги;
- возраст;
- количество лайков.

Если по выбранному возрасту ничего не найдено, показывается сообщение «Нет услуг по выбранным фильтрам».

### Добавление — `/add`

**Поля формы (отключены для гостя):**

| Лента | пункт нижней панели | Перейти на страницу «Лента» |
| Добавление | пункт нижней панели | Отключён для гостя |

## Нижняя навигация

Navbar из 4 пунктов:

1. **Лента** — доступна;

3. **Плитка** — доступна;
4. **Вход** — недоступен для гостя.

## Mock-данные

Коллекция находится в `src/collections/services.ts`. Каждый объект услуги содержит:

```ts
interface Service {
  id: string
  title: string
  description: string
  category: string
  price: number
  date: string
  age?: number
  pressure?: number
  likes: number
  imageUrl?: string
  videoUrl?: string
}
```

В коллекции 6 услуг. У всех услуг поля `imageUrl` и `videoUrl` пустые, поэтому везде показываются одинаковые медиа по умолчанию.

## Медиа по умолчанию

- `src/assets/default-image.svg` — единое изображение по умолчанию;
- `src/assets/default-video.mp4` — единое видео по умолчанию;
- `src/components/ServiceMedia.tsx` — компонент, который подставляет медиа по умолчанию, если поле пустое или файл не загрузился.

## Фильтрация

Компонент `src/components/ServiceFilter.tsx` — управляемый компонент. Он получает props:

- `values` — текущие значения фильтра `{ minAge, maxAge }`;
- `onChange` — обновление значений при движении ползунков;
- `onApply` — применение фильтра.

Страница плитки хранит два состояния: черновик фильтра и применённый фильтр. Список услуг пересчитывается через `useMemo`.

## Используемые хуки

- `useState` — состояние ленты, лайков, фильтра и применённого фильтра;
- `useEffect` — установка заголовка документа при смене услуги;
- `useMemo` — вычисление отфильтрованного списка услуг;
- `useSearchParams` — получение `service` из URL, чтобы открыть нужную услугу из плитки.

## Структура проекта

```text
src/
  assets/            изображение и видео по умолчанию
  collections/       mock-коллекция услуг
  components/        layout, navbar, карточки, фильтр, медиа, иконки
  pages/             FeedPage, GridPage, AddPage
  App.tsx            маршруты
  main.tsx           точка входа, Bootstrap CSS, BrowserRouter
```

## Ограничения

- Бэкенд не используется: все карточки берут данные из mock-коллекции.
- Redux и Context не используются.
- Авторизации нет: гость видит только ленту и плитку.
- Лайки и фильтр хранятся только в состоянии страницы и сбрасываются при перезагрузке.
