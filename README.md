# CAVI Мониторинг — фронтенд (лабораторная 5)

SPA на `React` + `TypeScript` (сборщик `Vite`) с компонентами `React-Bootstrap`.
Интерфейс для **гостя**: просмотр услуг (CAVI-мониторинг) — их возраста и давления.
Данные карточек берутся только из коллекции `mock`-объектов (`src/collections/services.ts`), бэкенд не используется.

## Общие элементы всех страниц

- **Статус-бар** сверху (время и значки) — макет экрана телефона из лаб. 1.
- **Навигационная панель** снизу из 4 пунктов:

| Пункт | Адрес | Доступность |
|---|---|---|
| Лента | `/feed` | доступен |
| Добавление | — | недоступен (серый) |
| Плитка | `/grid` | доступен |
| Вход | — | недоступен (серый) |

Пункт текущей страницы выделен цветом и фоном.

## Страница «Лента» — `/feed` и `/feed?service=<id>`

Одна услуга на весь экран.

- `/feed` — первая услуга, `/feed?service=<id>` — услуга с указанным `id`.
- Если услуги с таким `id` нет, показывается первая услуга.

Полей ввода нет.

| Элемент | Тип | Назначение |
|---|---|---|
| Видео | фон | видео услуги на весь экран (автовоспроизведение, без звука, по кругу); если поле пустое — видео по умолчанию |
| Изображение | `poster` видео | изображение услуги; если поле пустое — изображение по умолчанию |
| «Возраст … лет / Давление … мм» | текст | характеристики услуги |
| Сердце и число | кнопка | поставить или убрать лайк; счётчик меняется в состоянии страницы |
| Стрелка вправо | кнопка | переход к следующей услуге (после последней — снова первая) |
| Название, описание, «Ещё» | текст | название и описание услуги (описание обрезано до 2 строк), «Ещё» ведёт на «Плитку» |

## Страница «Плитка» — `/grid`

Каталог услуг карточками в две колонки и фильтр по возрасту.

| Элемент | Тип | Назначение |
|---|---|---|
| «Плитка» | заголовок | — |
| Левый ползунок | поле (`range`) | минимальный возраст, 0–100, шаг 1 |
| Правый ползунок | поле (`range`) | максимальный возраст, 0–100, шаг 1 |
| «Возраст: от … до …» | текст | текущие значения ползунков |
| «Применить» | кнопка | применяет фильтр: остаются услуги с возрастом в выбранном диапазоне |
| Карточка услуги | ссылка | изображение по умолчанию, название, возраст и количество лайков; нажатие открывает услугу в «Ленте» |

При открытии страницы показываются все услуги. Если по выбранному возрасту ничего не найдено, выводится сообщение «Нет услуг по выбранным фильтрам».

## Страница «Добавление» — `/add`

Третий экран приложения. Для гостя недоступен: пункт «Добавление» в нижней панели отключён.

| Элемент | Тип | Назначение |
|---|---|---|
| Название | текстовое поле | название услуги, отключено для гостя |
| Краткое описание | многострочное поле | описание услуги, отключено для гостя |
| Цена, ₽ | числовое поле | стоимость услуги, отключено для гостя |
| Дата | поле выбора даты | дата оказания услуги, отключено для гостя |
| Категория | выпадающий список | категория услуги, отключён для гостя |
| «Добавить» | кнопка | отключена для гостя |
| «Вернуться в ленту» | ссылка | переход на `/feed` |

## Структура проекта

```text
src/
  main.tsx                      точка входа, роутер
  App.tsx                       маршруты
  components/AppLayout.tsx      общий макет: статус-бар, страница, navbar
  components/FeedCard.tsx       карточка ленты
  components/ServiceCard.tsx    карточка плитки
  components/ServiceFilter.tsx  фильтр по возрасту
  components/ServiceMedia.tsx   изображение и видео по умолчанию
  pages/FeedPage.tsx            страница «Лента»
  pages/GridPage.tsx            страница «Плитка»
  pages/AddPage.tsx             страница «Добавление»
  collections/services.ts       mock-коллекция услуг
  assets/                       изображение и видео по умолчанию
```
